### 1.2 触发方式（`Modules/ModEvent.vb` L262-315，逐字抄录）

PCL 内部用事件名分发，四个功能对应的事件名：

```vb
Case EventType.今日人品
    PageOtherTest.Jrrp()

Case EventType.内存优化
    RunInThread(Sub() PageOtherTest.MemoryOptimize(True))     ' ← 注意是后台线程

Case EventType.清理垃圾
    RunInThread(Sub() PageOtherTest.RubbishClear())           ' ← 同样是后台线程

Case EventType.下载文件
    ' 参数以 | 分割，三种形态：
    '   1 个参数(Url)                      → StartCustomDownload(Url, 从Url取文件名)
    '   2 个参数(Url, FileName)            → StartCustomDownload(Url, FileName)
    '   3 个参数(Url, FileName, Folder)    → StartCustomDownload(Url, FileName, Folder)
    Select Case Args.Length
        Case 1 : PageOtherTest.StartCustomDownload(Arg0, PathUtils.GetLastPart(Arg0))
        Case 2 : PageOtherTest.StartCustomDownload(Arg0, Arg1)
        Case Else : PageOtherTest.StartCustomDownload(Arg0, Args(1), Args(2))
    End Select
```

**★ 两个关键设计点（必须照抄）：**
1. **内存优化和清理垃圾都在后台线程跑**（`RunInThread`），不阻塞 UI。
2. **下载文件支持三种参数形态**，且"1 个参数"时会从 URL 自动推断文件名。

```
D:\HMCL-PE重构QCL计划\qcl-pc\

  src/main/ipc.js            IPC 白名单（★ 加通道必须同步改这里）
```

**★ 硬约束（踩过坑，别忘）：**
- `src/preload/index.js` 里的 `INVOKE_RE` 是 IPC 白名单，**新增任何 `xxx:yyy` 通道都要加进那个正则**，否则渲染层调用会报"不允许调用的通道"。
- 主进程用 `ipcMain.handle`，渲染层用 `window.qcl.xxx()`，中间必过 preload。

#### ① 内存优化 `MemoryOptimize(showHint)`

**⚠️ 这是唯一必须写清"能不能做到"的：**

Windows 上没有"释放物理内存"这回事。PCL 干的是**把工作集页刷出去**，让 Windows 的可用内存数字变大，代价是这些页面下次访问要重新从页面文件读回来。

**Windows 实现（Electron 主进程，用 FFI 或调用 PowerShell）：**

```js
// 方案 A：调 PowerShell（无需原生模块，推荐先用这个）
// EmptyWorkingSet 需要 SeProfileSingleProcessPrivilege，普通权限下只能对自己/同用户进程生效
const script = `
  $sig = '[DllImport("psapi.dll")] public static extern bool EmptyWorkingSet(IntPtr hProcess);'
  $t = Add-Type -MemberDefinition $sig -Name W -PassThru
  $sig2 = '[DllImport("kernel32.dll")] public static extern IntPtr OpenProcess(int a, bool b, int c);'
  $k = Add-Type -MemberDefinition $sig2 -Name K -PassThru
  $before = (Get-CimInstance Win32_OperatingSystem).FreePhysicalMemory
  Get-Process | ForEach-Object {
    try { $h = $k::OpenProcess(0x1F0FFF, $false, $_.Id); if ($h -ne [IntPtr]::Zero) { $t::EmptyWorkingSet($h) | Out-Null } } catch {}
  }
  $after = (Get-CimInstance Win32_OperatingSystem).FreePhysicalMemory
  "$before|$after"
`;
```

**★ 必须给玩家的诚实提示（PCL 也没骗人）：**
> "这条只把内存页刷到页面文件里，系统显示的可用内存会变大。它不会让程序变快，反而可能让刚切回的程序短暂卡顿。真正的内存不足请关掉不用的程序。"

**★ Android（QCL 手机版）做不到同样的效果**，只能 `onTrimMemory` + 杀自己进程的后台服务。**两版要分开实现，别假装一样。**

#### ② 清理游戏垃圾 `RubbishClear()`

**这个是纯文件操作，能完全做到。** 扫描目标（按 qcl-pc 的目录结构调整）：

```js
const CLEAN_TARGETS = [
  // 日志（保留最近 3 天）
  { glob: '.minecraft/logs/*.log*',        keepDays: 3 },
  { glob: '.minecraft/logs/*.gz',          keepDays: 3 },
  // 崩溃报告（保留最近 7 天）
  { glob: '.minecraft/crash-reports/*',    keepDays: 7 },
  // 各版本的日志
  { glob: '.minecraft/versions/*/*.log',   keepDays: 3 },
  // 下载残骸（一律删）
  { glob: '.minecraft/**/*.part',          keepDays: 0 },
  { glob: '.minecraft/**/*.tmp',           keepDays: 0 },
  { glob: '.minecraft/**/*.download',      keepDays: 0 },
  // 缓存的旧 jar 备份
  { glob: '.minecraft/libraries/**/*.bak', keepDays: 0 },
];
```

**交互设计（照 PCL 的思路）：**
1. 先**扫描**，算出「可清理 N 个文件，共 X MB」
2. 列出来让玩家**确认**（不要静默删）
3. 删完汇报「已清理 X MB」

**★ 安全底线：**
- 绝不动 `saves/`（存档）、`mods/`、`config/`、`resourcepacks/`
- 删除前检查路径是否在 `.minecraft` 之内（防符号链接逃逸）
- 走**回收站**（`shell.trashItem`）而不是 `fs.unlink`，给玩家后悔的机会

#### ④ 今日人品 `Jrrp()`

**确定性哈希：同一天、同一用户名 → 同一个结果。**

```js
const crypto = require('crypto');
function jrrp(username, dateStr) {
  const h = crypto.createHash('sha256')
    .update(`${username}|${dateStr}`)   // dateStr = 'YYYY-MM-DD'
    .digest();
  const score = h.readUInt32BE(0) % 101;  // 0..100
  return { score, text: pickText(score) };  // 60 以下/60-80/80-95/95+ 四档评语
}
```

**★ 一定要确定性**，否则玩家刷新出不同结果会觉得是假的。

#### ⑤ 回声洞 `GetRandomCave()` / 随机提示

**PCL 是随机显示作者与网友的留言。** qcl-pc 的做法：

- 内置一个本地 JSON（几百条短句），随机取一条
- 从网络拉更新（可选，失败就用本地）
- **反复点击同一个地方就再随机一条**（这就是截图里"反复点击这里"的含义）

#### ⑥ 下载自定义文件 `StartCustomDownload(url, fileName, folder)`

**qcl-pc 已经有下载能力（`src/main/core/` 里应该有），直接复用。**

要求：
- **多线程分块下载**（PCL 主打这个卖点）
- 显示进度、速度、剩余时间
- 支持暂停/继续
- 文件名留空时从 URL 推断（`PathUtils.GetLastPart` 的等价物）
- 保存目录默认 `PCL/MyDownload`（qcl-pc 里对应 `QCL/MyDownload`）

**PCL 的彩蛋。** 点下去随机弹一句沙雕话。qcl-pc 可以照抄：点 10 次后按钮文字变一次，或者点击后播放一个音效。

## 四、诚实申明（必须写进最终汇报）

1. **PCL 开源版把百宝箱挖空了**，所有方法体只剩一句 Hint。本文档的**功能清单、方法签名、触发方式**是从源码抄的（可信）；**实现细节是推定**（内存用 EmptyWorkingSet、垃圾扫描的目录清单等）。
2. **内存优化在任何平台都不会"凭空变快"**，它只是把页面刷出物理内存。UI 上必须说清楚，不能宣传成"提速"。
3. **Android 版（QCL 手机端）做不到同样的内存优化**，两版要分别实现，不能共用一个说法。
