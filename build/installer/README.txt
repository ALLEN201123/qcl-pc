; ============================================================================
;  Quanta Craft Launcher PC · 安装脚本（7-Zip SFX 用的，静默 + 中文提示）
;
;  ★ 为什么走这条路而不是 NSIS：
;     NSIS（makensis）无论用 solid 包还是 File /r，最终都要把待压缩的数据
;     整块 mmap 进内存。本机可用内存常年 1 GB 上下，
;     实测报 `error creating mmap the size of 214871488` —— 这条路在本机走不通。
;
;  ★ 7z SFX 的方案：
;     自解压引导头（7z.sfx）解压时只需要流式读写，内存占用极小。
;     但它自带的「Extract / Cancel」对话框是英文硬编码 ——
;     所以这里用 `InstallPath` + `RunProgram` + `AutoInstall` 让**解压过程无对话框**，
;     用户看到的是干净的「正在安装 → 自动启动 QCL」，
;     安装完成后由 QCL 自己显示中文界面与引导。
; ============================================================================
