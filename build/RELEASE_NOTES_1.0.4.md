# QCL 电脑版 1.0.4

Windows 上的 Minecraft Java 版启动器，全中文界面，基于 Electron。**双击安装包即装，无需管理员权限，不依赖任何外部运行库。**

## 下载

- **`QCL-Setup-1.0.4.exe`**（约 128 MB，中文自解压安装程序）← 本 Release 的 Assets
- 仓库：<https://github.com/ALLEN201123/qcl-pc>
- 许可：GNU GPL-3.0

装完在「设置 → 关于」里应显示 `QCL 1.0.4`。装之前请先关掉正在运行的旧版 QCL。

> 说明：GitHub 会过滤 Release 资产名里的中文，因此附件用 ASCII 名 `QCL-Setup-1.0.4.exe`；
> 它与本地 `QCL-安装程序-1.0.4.exe` 是同一个文件。

## 本版新增：百宝箱

入口在**左侧常驻导航栏**，「工具」下面一项，带专属的宝箱图标。

功能清单、方法签名、触发方式照 **PCL 官方开源仓库**（`Meloong-Git/PCL` 的
`PageOtherTest.xaml.vb` + `Modules/ModEvent.vb` L262-315）实现。

### 六个功能

| 功能 | 说明 |
|---|---|
| **今日人品** | 用户名 + 日期的确定性哈希。同一天同一账号结果**永远固定**，跨天才变（实测连算 20 次结果唯一）。 |
| **内存优化** | 调用 `psapi!EmptyWorkingSet` 把进程工作集页刷到页面文件。**实机实测释放约 960 MB / 处理 145 个进程。** |
| **清理游戏垃圾** | 先扫描 → 列出清单 → 玩家确认 → **走回收站**删除。只清日志 / 崩溃报告 / 下载残骸。 |
| **磁盘占用** | 按 `.minecraft` 一级子目录统计体积，降序排列，每项可一键打开。**只统计，不删除。** |
| **回声洞** | 内置 30 条留言 + 10 条实用提示，反复点不断出新，完全离线。 |
| **下载自定义文件** | 填地址即可下载；文件名留空从 URL 推断；保存目录可自选（默认 `主目录/MyDownload`）；显示进度与速度。 |
| 千万别点 | 彩蛋，点了只弹一句废话。 |

### ★ 关于「内存优化」的诚实说明

这条**不会让电脑变快**。它只是把进程的工作集页刷到页面文件里，
系统显示的「可用内存」会变大；代价是这些页面下次访问要从磁盘读回来，
**刚切回的程序可能短暂卡顿**。真正的内存不足请关掉不用的程序。

界面上就是这么写的，没有包装成「加速」或「释放物理内存」。

### ★ 清理垃圾的安全底线

代码里写死三层保护，不靠调用方自觉：

1. **只删白名单**：`logs/`、`crash-reports/`、`versions/*/*.log`、`*.part`/`*.tmp`/`*.download`、`libraries/**/*.bak`
2. **绝不触碰** `saves` / `mods` / `config` / `resourcepacks` / `shaderpacks` / `screenshots` / `schematics`
   —— 这些目录连**遍历都会跳过**，所以里面的残骸也不会被扫到
3. **路径校验**：每个待删文件都要确认真实路径在 `.minecraft` 之内（防符号链接逃逸）
4. **走回收站**（`shell.trashItem`），不是直接删除，可以还原

### 百宝箱专属图标

不是借用星星图标，是单独画的**宝箱造型**：箱盖（带弧度）+ 箱体 + 中缝 + 正面锁扣 + 锁孔，
5 条 path，`currentColor` 上色，深色/浅色主题都清晰。导航栏与页面标题都用它。
